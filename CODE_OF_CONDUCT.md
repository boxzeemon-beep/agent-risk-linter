# Code of Conduct

Be respectful, specific, and constructive. Discuss behavior and evidence rather than attacking people. Harassment, discrimination, threats, doxxing, and publication of private data or credentials are not accepted.

Security research must remain authorized and defensive. Do not pressure contributors to run unknown code or disclose sensitive material. Maintainers may edit or remove unsafe content and may restrict participation when necessary to protect contributors or users.

Report conduct concerns privately through the repository owner's GitHub profile or, when security information is involved, through private vulnerability reporting. Enforcement decisions will prioritize safety, proportionality, and a clear path to resolution where practical.
